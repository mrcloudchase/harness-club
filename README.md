# Harness Club

A builder club for harness engineering. No sales bullshit.

**Site:** https://mrcloudchase.github.io/harness-club/
**Discord:** https://discord.gg/fhZzuRgpvH

## What it is

Harness Club is a group of builders who do harness engineering. We meet to learn it and to build it.

The model is the mind. The harness is the body: the loop, the tools, the context. We build our own harnesses so we understand every part and decide how it works. The best harness is the one you control.

## How it goes

**The starter harness.** We start with an intro to the [curriculum](https://github.com/averagejoeslab/harness-engineering) and build a working harness from scratch, one runnable step at a time:

1. Reach the model
2. Let someone ask
3. Let it act
4. Let it keep going
5. Give it context

**Push the bounds.** After that, we try things: new tools, different loops, other ways to manage context, harder tasks. We break harnesses, fix them, and show each other what worked.

## The rules

1. The first rule of Harness Club: you ~~do not~~ **DO** talk about Harness Club.
2. Everyone is here to learn. Ask anything.
3. The best harness is the one you control. Build your own.
4. No sales. No pitches. No pricing slides.
5. Bring any model. The harness is the work.
6. If it hasn't run, it isn't a demo.
7. Builds go on as long as they have to.
8. If this is your first night at Harness Club, you build.
