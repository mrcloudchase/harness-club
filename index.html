// why we're here

What it is

Harness Club is a group of builders who do harness engineering. We meet to learn it and to build it.

The model is the mind. The harness is the body: the loop, the tools, the context, the guardrails.

We build our own harnesses so we understand every part and decide how it works.

// how it goes

Start with the basics.
Then push the bounds.

First, everyone

The starter harness

We start with an intro to the curriculum and build a working harness from scratch, one runnable step at a time.

  1. 1Reach the model 1_model_interface.py
  2. 2Let someone ask 2_input.py
  3. 3Let it act 3_output.py
  4. 4Let it keep going 4_control_flow.py
  5. 5Give it context harness.py
Then, every time after

Push the bounds

After that, we try things: new tools, different loops, other ways to manage context, tighter guardrails, harder tasks.

We break harnesses, fix them, and show each other what worked.

// house rules

The rules

Rules of Harness Club

  1. The first rule of Harness Club: you do not DO talk about Harness Club.
  2. Everyone is here to learn. Ask anything.
  3. The best harness is the one you control. Build your own.
  4. No sales. No pitches. No pricing slides.
  5. Bring any model. The harness is the work.
  6. If it hasn't run, it isn't a demo.
  7. Builds go on as long as they have to.
  8. If this is your first night at Harness Club, you build.
